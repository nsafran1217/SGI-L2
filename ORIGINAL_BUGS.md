# Bugs in the original SGI code

Found while reconstructing. Each entry says whether the reconstruction keeps
the original behaviour (so output matches the shipped binaries) or fixes it.
The rule: keep it when the bug shapes normal output; fix it when the original
only misbehaves in cases that print garbage or crash anyway.

| Where | Bug | Decision |
|---|---|---|
| `l3/sys/syslogLib.c` `syslog()` | Levels 0–2 build the prefix with `sprintf(buf, "%s: %s line %d ; ", hwType, msgno, level_text, file, line)`: five arguments for three conversions, so `msgno` is printed by the second `%s` ("(null)" when 0) and `%d` gets a pointer. Verified in the machine code. | **Kept**, spelled out portably: msgno 0 prints glibc's "(null)" and the level text's address goes to `%d`, as on i386. A nonzero msgno (a wild pointer in the original) prints as a number. |
| `l3/main/nvram.c` `nvramLogFinsert()` | Passes its `va_list` to `snprintf` instead of `vsnprintf`, so any `%` conversion in `fmt` prints garbage. Verified in the machine code. | **Fixed** (`vsnprintf`). Identical output for format strings without conversions. |
| `common/main/EnetServer.c` `EnetServerConnect()` | "could not get IP value for host %s:%d" is passed `host` only, so `%d` prints stack garbage. Verified in the machine code. | **Fixed:** passes `port`, the evident intent. Identical except in the line that printed garbage. |
| `l3/l2/l2cmd.c`, `l3/sys/syslogLib.c` | Some `sprintf`/`fprintf` calls pass more arguments than their format uses (`syslog`'s console writes pass six trailing zeros). Verified in the machine code. | **Kept.** Harmless. |
| `common/sys/Cmd.c` `CmdFormat()` | Builds usage text in a 40-byte static buffer (`fmt.8`, 0x28 bytes in the binary) with `strcat` and no length check. `help` overflows it (found by ASan) into the next static. | **Fixed:** 256 bytes. The text was always complete; only the neighbour got clobbered. |
| `common/main/L2Cfg.c` `L2CfgMCfgL2()` (`l2pri`) | Deletes secondary peers while walking the list, reading `peer->next` after `L2CfgMDeleteL2Peer()` freed the peer. | **Fixed:** saves `next` first. |
| `l3/l2/l2cmd.c` `l2cmd_power()` (`power` status) | Counts `power_state == -1` as "other", but `power_state` is a `uint8`, so "other" is always 0. Verified in the machine code (`movzbl`, `cmp $-1`). | **Kept.** Shapes the status line. |
| `common/Router/Router.c` `RouterPack()`/`RouterUnpack()` | Inline (class 0) argument values are written unconverted but read back with `ntohl`, so between two i386 hosts they arrive byte-swapped. Verified in the machine code (one `htonl` in `RouterPack`, two `ntohl` in `RouterUnpack`). | **Kept** as wire behaviour: written little-endian and read big-endian explicitly, so every host matches the i386 originals. |
| `common/IRouter/IRouter.c` `IRouterSetFrameByteOrder()` | Swaps frame fields with `ntohs`/`ntohl`/`htons`/`htonl`, which are no-ops on a big-endian host, so a big-endian host never converts a little-endian frame. | **Fixed:** unconditional byte swaps (the same operations on i386). |
| `common/Router/Router.c` `RouterPack()` | Pads each argument to 4 bytes in a `malloc`ed buffer without initializing the padding, so up to 3 bytes of heap memory per argument go out on the wire (seen in l2gui's command packets). | **Fixed:** the padding is zeroed. Receivers ignore it. |
| `l3/gui/destwin.cc` `remove_dest()` | Deselecting a rack, slot or partition is meant to close the range around it, but the second test repeats `== 2 \|\| == 3` (the first block has just cleared that entry), so deselecting the last entry of a range leaves the range open. Verified in the machine code. | **Kept.** Shapes the destination string. |
| `l3/gui/destwin.cc` `update_dest()` | "selected rack (%d) is not part of current config" is passed no argument. Verified in the machine code. | **Fixed:** passes the rack number. |
| `l3/gui/destwin.cc` `destwin_update_config()` | `list_insert()` returns without setting the index for rack 0, which then indexes `slotlist` uninitialized. | **Fixed:** the index starts at 0. Identical for configurations without rack 0. |
| `l3/gui/destwin.cc` `dest_is_rack()` | Counts 256 entries of the 64-entry partition list. | **Kept**; nothing calls it. |
| `l3/l2/l2cmd.c` `ver_summary_rsp()` (`version summary`, also run by `power up`) | `sscanf("L%[12]...", &junk1, ...)` into `char junk1`: `%[` stores a NUL too, one byte past it (found by ASan with a fake L1). In the original the byte lands on `rptr`, which is reassigned before its next use. | **Fixed:** `char junk1[2]`. No output change. |
| `l3/api/L1Direct.c` `format_address()` | Case 0 (an L1 rack.slot address) has no `break`: its "%03d.%02d" text is overwritten by case 3's "local attached C". Verified in the machine code. | **Kept** (l2term/l2cmd/l2gui direct-L1 messages). |
| `common/Router/Buff.c` `BuffCompress()` (Router link compression) | Allocates 2.5 output bytes per input byte, but a lone escape byte (0xfe/0xfd) is coded in 3: data heavy in those bytes overflows the heap. | **Fixed** on the rewrite branch (3 per byte). Same output; `tests/unit/buff_test.sh` compares it with the original. |
| `common/Router/Buff.c` `BuffUncompress()` | Trusts the packet: a truncated run token or counts beyond the stated length run past the input or output buffer. | **Fixed** on the rewrite branch: rejected (-1). |
| `common/Router/Socket.c` `SocketSetBufferSize()` | Reads the old send buffer size from `SO_RCVBUF`, so "ERROR! SO_SNDBUF size failed (was N, ...)" reports the receive buffer. | **Kept** (message text). |
| `common/Router/Event.c` `EventIOListAlloc()` | Growing the descriptor table clears only the new fd's entry; entries between the old size and it stay uninitialized. | **Fixed** on the rewrite branch (all new entries cleared). |
| `common/Router/Router.c` `RouterProcessConfig*()` | Reads only the low three bytes of the peer's config `rev` and `flags`, so the compression flag (bit 31) never arrives: Router compression is never used. Verified in the machine code. | **Kept** (fixing it would turn compression on between links). |
| `common/Router/Router.c` `RouterQRetrieve()` | Leaves the retrieved entry's `next` link set. A sent request moved from the output to the input queue can still point into the output queue; freeing the connection then frees those entries twice. | **Fixed** on the rewrite branch. |
| `common/Router/Router.c` `RouterProcessResponse()` | Unlinking a matched request that is the last of several leaves the queue's tail on the freed entry. | **Fixed** on the rewrite branch. |
| `common/Router/Router.c` `RouterFreeEntry()` | Hands a sent reliable request back to its error callback by unpacking its header in wire order (garbage length on little-endian hosts). | **Fixed** on the rewrite branch (host-order header restored first). |
| `common/Router/Router.c` `RouterUnpackID()` (was inline in RouterCl.c/RouterSv.c) | Copies the peer's process, user and full names into fixed-size fields without a bound. | **Fixed** on the rewrite branch (truncated). |
| `common/sys/Logger.c` `LogError()`, `LogErrorHost()`; `common/Router/Router.c` `RouterLogError()` | Varargs wrappers that pass their `va_list` on to the varargs `LoggerLogMessage()` as an ordinary argument, so a conversion in the text (`"%s"` with the socket path, `"ID = %d"`) prints the `va_list` pointer. Verified in the machine code (`lea` of the first vararg pushed as the eighth argument). The reconstruction on main dropped those arguments altogether. | **Fixed** on the rewrite branch: `LoggerVLogMessage()` takes the `va_list`; the prototypes carry `format(printf)` checks and the three calls have their arguments back. |
| `common/sys/Logger.c` `LoggerDefaultMessage()`, `LoggerErrorMessage()`, `LoggerModuleMessage()` | Module numbers are accepted down to -1099, one module past the table, whose empty end entry gives a "(null)" module name; -1000 dereferences its NULL message list. Within a module the index may equal the list's count, one past its NULL end (and the NULL itself prints "(null)"). Verified in the machine code (`cmp $-1000`, `jl`). | **Fixed** on the rewrite branch: such numbers are "Unknown Module"/"Unknown Message". |
| `common/sys/Logger.c` `LoggerLogMessage()`, `LoggerFormat()` | `vsprintf` into a 1025-byte stack buffer, then the whole entry `strcat`ed into a 1025-byte static, with no bounds. | **Fixed** on the rewrite branch (truncated to the buffers). |
| `common/sys/BuffWrite.c` `BuffWrite()` | Grows the buffer only when the text, not counting its terminator, would not fit, so a text that fills it exactly gets its NUL one byte past the end (found by ASan in `tests/unit/buffwrite_test.c`). Copies with `strcpy`, so a `len` shorter than the string is not honoured. | **Fixed** on the rewrite branch. Every call passes the string's length, so the text is unchanged. |
| `common/sys/ipmi.c` `ipmiCalcCSum()` | Decrements `bytes` before testing it, so 0 bytes runs over 4 GB of memory. | **Fixed** on the rewrite branch (0 for an empty area). Always called with a size. |
| `common/sys/Cmd.c` `CmdProcess()` (`<rack><c><slot>` token) | Marks `rlist[rack % 256]` and `slist[slot % 256]`, but there are 64 slots: slots 64–127 land in `plist` (cleared next), and 128 and up write past `CmdData`, which ends at the frame pointer, into the saved `ebp`, return address and the caller's frame (verified: `l2cmd 1c130 l1 ver` kills the original `l2` with signal 11). A negative rack writes before `rlist`. | **Fixed** on the rewrite branch: numbers outside the lists select nothing, as slots 64–127 did. |
| `common/sys/Cmd.c` `CmdProcess()` | Copies the command line into a 256-byte buffer with `strcpy`. | **Fixed** on the rewrite branch: a longer line matches nothing. |
| `common/sys/Cmd.c` `CmdProcess()` | When a command returns -2 (bad arguments), prints `toks[0]` into an 80-byte buffer: a long word overflows it, and for a form starting with a destination `toks[0]` is the type number, which crashes `sprintf`. | **Fixed** on the rewrite branch: the first word, in a buffer sized for it. |
| `common/sys/Cmd.c` `CmdHelpAll()`, `CmdHelpCmd()` | Classify a token by `(int)` of the pointer, so on 64-bit a word whose address' low half is 6–12 counts as a token type. | **Fixed** on the rewrite branch (compared as `uintptr_t`). |
| `common/sys/Cmd.c` `CmdAddCmds()` | Logs "command list full!" and stores the eleventh table past the array anyway. | **Fixed** on the rewrite branch (not added; returns -1). |
| `common/sys/brick_types.c` `brickConvertType()` | `strcpy`s display names into a 16-byte static; "Quad Dense Router" (`-`) and "C (IP69 HACK, 1932 Chassis)" (`$`) are longer and overwrite the start of the next static (`pool`, minfo's block list, 24 bytes on). | **Fixed** on the rewrite branch (32 bytes). Same text. |
| `common/sys/minfo.c` `MInfoStatPrint()` | Sizes its report as 30 bytes per tracked block plus 100, but the fixed text alone is about 170 bytes, so with fewer than three blocks it overflows (found by ASan in `tests/unit/minfo_test.c`). | **Fixed** on the rewrite branch (200 more). |
| `common/sys/minfo.c` `MInfoMapPrint()` | 40 bytes per line, too few for lines with 64-bit addresses. | **Fixed** on the rewrite branch (80). |
| `common/sys/minfo.c` `MInfoStatPrint()` | Counts holes in 1 KB buckets of `mhole[104857]` without a bound, so a gap over 100 MB between tracked blocks indexes past it. Only buckets under 1 MB are printed. | **Fixed** on the rewrite branch: larger holes count toward "available memory" only, as they did in the output. |
| `l3/main/nvram.c` `nvramLogFetch()` | Meant to read a wrapped log ring in two pieces, but tests `head < tail` a second time where it means `tail < head` (verified in the machine code: the same `cmp`/`jbe` twice), so once the log has wrapped, `log` shows nothing. | **Kept** on the rewrite branch (shapes the output of `log`); to fix on modern. |
| `l3/main/nvram.c` `nvramReset()` / `nvramLogInsert()` | `nvram reset` zeroes the settings area, log ring offsets included, and l2 keeps running ("reboot required"); the next log message searches the empty ring for a newline. Verified: after `l2cmd nvram reset` the original `l2` segfaults at the next connection. | **Fixed** on the rewrite branch: messages are dropped until the next start, which resets the ring as before. |
| `l3/main/nvram.c` `nvramLogInsert()` | Checks whether an empty message ends in a newline by reading the byte before it. | **Fixed** on the rewrite branch (an empty message gets one). |
